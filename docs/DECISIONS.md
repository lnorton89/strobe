# Decisions

This is an append-only log of choices that aren't obvious from the code.
Each entry has a date, the decision, why it was made, and what would
reopen it. To reverse a decision, add a new entry that says so; don't
edit the old one (an *Addendum* paragraph in the old one is fine).

**Each decision is its own file** in [`decisions/`](decisions/), named
for its number: `decisions/D12.md` holds D12, with the heading
`# D12: <the decision> (<date>, <who chose>)`. That way two branches that
each add a decision never touch the same file (D531).

To add one, take the next number after the highest file in `decisions/`
on `origin/master` and on any open pull request you know of. If two
branches still pick the same number, the second to merge shows an add/add
conflict on that file name: renumber it there and fix its citations.

`strobe_conventions::docs` fails the build when a Markdown file cites a
`D<n>` that has no file, or when a file's name and heading disagree.

To find the decisions about one crate, use
[`DECISIONS_BY_AREA.md`](DECISIONS_BY_AREA.md): every decision under each
crate it names, generated by `cargo xtask decisions` and checked by CI's
`generated` lane (D539).
