# D574: A second Spout sender carries a clean feed, before the post stage and never blacked out

Date: 2026-11-26
Status: Accepted
Areas: output, app
Backlog: M-06
Related: D573, D570, D180, D135

## Context

Issue lnorton89/strobe#116 asks for several Spout senders at once, each with
a name of its own. The survey in D573 found the same in Resolume (an
Advanced Output screen per sender), MadMapper (one per output) and OBS (a
Spout filter per source).

Several senders carrying the same picture would only be copies. What makes a
second sender useful is that it carries a different picture. For a VJ engine
feeding a mixer, the common case is the raw scene beside the show's output,
so the mixer can apply its own look, or keep the picture up while the
projector is blacked out.

## Decision

A **clean feed**: a second, optional Spout sender with its own name, default
`Strobe Clean`.

- **Its picture** is the scene's output, or the compositor's mix during a
  transition: before the post stage (D180), so before master, colour and the
  mirrors.
- **Blackout leaves it alone**, which is the other half of D573's choice: the
  main sender goes dark with the projector, and the clean feed does not.
- **Its size** is the same shared size as the main sender. It has its own
  share stage for the scaled draw, so the two never overwrite each other.
- **Its name must differ from the main sender's.** If both are the same, the
  clean feed is refused with a note on the Spout row.
- **Where it is set:** Settings > Output > Sharing > *Clean feed* has a
  switch and a name field, and both are saved. `--spout-clean NAME` turns it
  on for one run.
- **Spout only.** A clean NDI stream would be a second readback and a second
  network stream, so it waits until someone needs it. Spout is nearly free:
  zero-copy at the picture's size, one draw at a fixed size.

## Consequences

- With both senders on and a fixed size, the cost is two scaled draws a
  frame, about 0.27 ms of GPU each at 1080p on the RX 580 (BENCHMARKS.md,
  2026-11-26). At the picture's size it costs nothing.
- Verified on LIGHTNING: `--spout StrobeMain --spout-clean StrobeRaw
  --share-size 1280x720` is listed as two senders at 1280x720 by the
  receiver-side probe, and both are gone after a clean exit.
- More senders than two, or a clean NDI feed, would generalise this into a
  list of senders, each with a source (show or clean), a protocol and a name.
  That is not built.
