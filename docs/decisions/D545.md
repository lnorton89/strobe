# D545: other scene folders are searched through their subfolders (2026-11-04, owner's request)

A scene folder added in Settings (D538), `user-scenes` included, listed
only the scenes directly inside it. A folder of scenes kept inside it
(`user-scenes/jaja`) was not listed unless it was added as a folder of
its own.

- Each other scene folder is searched with `load::scan_deep` down to
  Synesthesia's default search depth (`synesthesia::DEFAULT_DEPTH`, 10
  levels), as Synesthesia searches its own scene folders (D271). A scene
  folder is not looked inside, links are not followed, and the walk stops
  after 20,000 folders, so a folder naming a whole drive
  cannot stall a rescan.
- The count in Settings is every scene the folder listed, subfolders
  included. A subfolder that is also added by hand lists nothing twice:
  a scene already listed is skipped, as before.
- The library folder itself is still scanned one level deep. Imports,
  the editor's new scene and the name checks write and look directly
  inside it, and nothing nests there.
