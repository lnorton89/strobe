# D560: From image makes scenes from a picture by templates, neural recognition and the visitor's own LLM, and a person picks (2026-11-06, owner's request)

**Context.** The owner asked for a feature on the website that turns a picture
into an audio-reactive scene inspired by it, with its controls, without an LLM
if possible, and then accepted neural nets, free server-side options on the
Cloudflare free tier, and an optional LLM by sign-in or API key.

Research for this measured what an LLM's image-derived scenes actually did: about
a quarter of its decisions came from pixels, about two fifths needed recognising
the subject, and the rest was taste, largely one repeated grammar. Classical
measures run on the real reference photos with thresholds frozen beforehand
recovered dominant colour and mirror symmetry, and did not recover layout or
element counts: layout scored below always answering the commonest class. On the
same photos CLIP's image encoder against fixed sentences read the wheel and the
grid that classical layout had missed, and it named subjects badly. No
non-LLM product was found that derives editable GLSL structure from a picture.

**Decision.**

- **It is a variant generator, not a converter.** A text-only scene comes from
  an original template library in `site/src/lib/play/image/`: thirteen templates
  over six layouts, with the shared clock, ink and tone. A picture supplies
  colours and a few measured control defaults. Pixels are never sampled, and no
  file name reaches a scene. The library's breadth is the ceiling on what this
  path can make, and that is said plainly: on a figurative painting it gives the
  picture's colours and rhythm, not its subject.
- **A person decides, because no measure can.** The panel shows a first reading
  as chips with one-click overrides for layout, motif and mood, four corners to
  mark and straighten the art, and a gallery of up to nine playing candidates.
  Candidates are chosen for spread, so a wrong reading still leaves other
  layouts on the page. No aesthetic score ranks them: the published ones do not
  hold up on this kind of work.
- **Gates reject only defects.** `gate.ts` plays each candidate through the real
  engine on a hidden canvas (ES 3.00) and rejects compile failures, black, flat,
  blown-out and frozen frames, and flashing by the WCAG 2.3.1 and ITU-R BT.1702
  luminance rule over a quarter of the screen. The wording is "screened", never
  "safe", since that is not a certificate. Halos fade before a cell's edge by
  construction, the commonest defect in the hand-made scenes.
- **Generated controls come from each template's manifest**, not from static
  mining: the template knows that a number is a stroke width. Each has a
  description saying what zero means, and defaults come from the measures.
  Generate controls (D558) still works on the result.
- **Recognition comes in layers, each optional, and each says where the picture
  goes before it is pressed.** The measures are instant and local. CLIP's vision
  half runs in the browser after an 89 MB download once, with this repository's
  precomputed text vectors (`scripts/clip-concepts.mjs`), so it holds no text
  encoder, writes nothing and cannot be prompted. The free service is
  `POST /api/read-image`, which sends a 512-pixel copy to a vision model on
  Workers AI inside the free 10,000 Neurons a day, rate limited per visitor,
  storing and logging nothing, and answering only with our own words
  (`cleanReading`). This extends D524 and D527 by exactly that one stateless
  route; storing uploads remains ruled out.
- **The library and wasm for CLIP are this site's own files**, copied at build
  from pinned packages (`scripts/copy-clip.mjs`), so a page that may hold a
  visitor's API key runs no script from another site. The weights are served from
  this site's own R2 bucket at `/api/models/`, a fixed list of three files, filled
  by `npm run upload:clip`. Hugging Face's CDN answers 404 to a `workers.dev`
  Referer (found on the first deploy, 2026-11-06), and sending no Referer to get
  past what looks like a deliberate block was rejected. R2's egress is free.
- **A visitor's own LLM goes direct.** The browser calls OpenRouter, Anthropic,
  OpenAI or Google itself, and the Worker never sees a key or that picture. All
  four answer a browser's CORS preflight (checked 2026-11-06). Sign-in is
  OpenRouter's OAuth with PKCE, the one real way for a third-party site to get a
  key. OpenAI, Anthropic and Google take an API key, because they offer no
  sign-in a third-party site may use with a consumer subscription, and scraping
  or borrowing one would break their terms. Google's OAuth for Gemini is possible
  but needs this project's own verified client and was left out. A key lives in
  page memory and the tab's storage, and in the browser's only when asked; Forget
  clears both. Models are listed by the provider, so a new one needs no release.
- **The LLM is an untrusted author.** Its reply can only become one `main.glsl`
  and one `scene.json` with an allowed set of keys, compiled by the real engine.
  It never gets `script.js`, `IMAGES`, `MEDIA` or `PASS_SOURCES`. Compile errors
  go back up to three times, then a rendered frame goes back for critique for up
  to three rounds, the same loop the hand-made scenes came from, and a round that
  breaks a passing scene does not replace it.
- **Generated scenes carry no licence stamp.** Which licence they should carry is
  still the owner's decision, and the hand-made scenes' MIT stamp is not a model
  to copy (D526, D532). Sharing a generated scene uses the same public, permanent
  store as any other.

**Rejected.**

- *Differentiable rendering and free genetic programming:* a browser compiles 9
  to 14 new programs a second against 1,700 to 3,500 uniform-only evaluations, and
  the closest differentiable system has non-commercial code.
- *Evolution-strategy fitting of uniforms to the picture:* not built yet. It has
  to beat plain template choice in a blind rating to earn its place, and per-pixel
  losses push toward copying.
- *A vision LLM writing GLSL on the free tier:* Workers AI's output tokens would
  spend the shared allowance in a few dozen scenes. The free service reads only.
- *CLIP naming the subject:* it called a jester a skull and a palm a sword.

**Consequences.** `/play` gains 22 MB of wasm that is only fetched when a visitor
asks for CLIP. Meta's licence had to be accepted once on the Cloudflare account
before the free service worked (below); the owner accepted it on 2026-11-06. An
account that has not answers that it is not switched on, and everything else
works. The deploy token has no Workers AI permission, so the command takes a
token of its own. What remains is in backlog W-04.

```bash
curl https://api.cloudflare.com/client/v4/accounts/$CLOUDFLARE_ACCOUNT_ID/ai/run/@cf/meta/llama-3.2-11b-vision-instruct -X POST -H "Authorization: Bearer $CLOUDFLARE_AUTH_TOKEN" -d '{"prompt": "agree"}'
```
