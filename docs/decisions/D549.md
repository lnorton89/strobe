# D549: master's history was rewritten so the owner is its only author, and the docs name the rewritten commits (2026-11-04, owner's request)

**Context.** About 800 of master's 1,005 commits were authored as
`Claude <noreply@anthropic.com>`, or carried a `Co-Authored-By` naming
Claude or a `Claude-Session` line. GitHub listed Claude as a contributor.
The owner wants to be the only author of their work, and chose a full
rewrite, release tags included, over rewriting only the commits since
v0.2.0.

**Decision.**

- **Every commit was rewritten** with `git filter-branch`:
  - an author or committer of `noreply@anthropic.com` became
    `Lawrence <lnorton89@gmail.com>`, with the same dates;
  - `Co-Authored-By` lines naming Claude or Anthropic, `Claude-Session:`
    lines and "Generated with Claude" lines were dropped;
  - nothing else changed. Every commit's tree is identical to the one it
    replaced; the old and new histories pair one to one (1,005 of 1,005).
- **The tags moved**, the one exception to "never move a tag"
  (CONTRIBUTING). v0.1.0 went from 578ea34 to a94ce33, and v0.2.0 from
  bbcccfb to e762f0b. Their trees are the trees that were released.
  - The published archives and their attestations are unchanged, but
    their provenance names the old commits, which are no longer on master.
  - Pushing the moved tags started the Release workflow from each tagged
    tree. That is the old workflow from before D521, so it does not refuse
    a published release. Both runs were cancelled during the build, before
    their upload step, and both releases' assets kept their original
    upload times.
- **What names commits was updated:**
  - CHANGELOG.md's released sections and the six `CHANGELOG.corrections`
    entries name the new hashes;
  - the docs' commit references, 153 in 15 files, were remapped through
    the rewrite's own old-to-new map. That covers the hardware records,
    BENCHMARKS, COMPATIBILITY, four decisions and the backlog.
  - Two hashes stay as written: a5d085d and d9a6ea6 existed only on the
    release dry-run mirror, never on master.
- **The 46 pull-request descriptions** that ended with "Generated with
  Claude Code" lost that line. From now on, commits and pull requests
  carry no AI attribution.

**Trade-off.**
- Every clone made before 2026-11-04 has the old history. It needs
  `git fetch --tags --force` and a reset to `origin/master`, or a fresh
  clone.
- A branch cut from the old history shows every rewritten commit as new
  until it is rebuilt on the new master.
- GitHub keeps the old commits reachable through closed pull requests'
  refs, but the contributor list counts the default branch.

**Test.**
- `git rev-parse` of each old and new commit's tree matched for all
  1,005.
- After the push, master and both tags on GitHub were the rewritten
  commits. `ci-ok` passed on the new tip. A scan of the rewritten messages
  found no `Co-Authored-By` or `Claude-Session` lines naming Claude.
- No pre-rewrite hash is left in the Markdown, apart from the two
  mirror-only ones.

**Would reopen:** nothing. A rewrite is not repeated; new commits are made
without attribution instead.
