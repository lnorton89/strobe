# D532: `user-scenes/` holds the owner's private scenes and is never committed (2026-11-03, owner's request)

Some scenes the owner works on are friends' art. Like Jester Totem (D526),
they have no license to be in this repository. They live in
`user-scenes/`, a scene library folder at the checkout's root that
`.gitignore` excludes, so no `git add` can stage them by accident.

Run the app on it with `--library user-scenes`. The scenes in `scenes/`
remain original work.

**Would reopen:** a scene in `user-scenes/` getting a license that allows
it here; then it moves to `scenes/` with its own decision.
