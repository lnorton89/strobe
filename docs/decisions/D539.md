# D539: property tests over untrusted input, weekly machete and coverage, and the decisions indexed by crate (2026-11-03, engineering audit)

**Context.** The last rows of the audit's table:
- targeted fuzz and property tests for the parsers and rewriters that read
  someone else's input, with failures minimised into permanent fixtures;
- a periodic unused-dependency check;
- periodic coverage of the pure-logic crates, used to find missing cases
  rather than as a percentage target;
- a way to read the decision log by subsystem without renumbering it.

The workspace denies `panic!` and `unwrap`, but an index out of range, a
slice past its end or an arithmetic overflow in a test build still
panics. Those are the bugs generated input finds.

**Decision.**

- **Property tests with proptest 1.12** (dev-only, `default-features =
  false`, `std`; no fork, no timeout, nothing nightly), one
  `tests/properties.rs` per crate. Each runs a `TestRunner` inside an
  ordinary `-> anyhow::Result<()>` test, and inputs are both arbitrary and
  shaped like the real thing:
  - **strobe-scene**: any `scene.json` text parses or is refused; tag lists
    stay bounded; the GLSL rewriters (`passindex_float_compares`,
    `pow_as_exp2_log2`, `int_to_float` in both dialects) never panic and
    never grow their input more than eight times plus 4 KiB.
  - **strobe-playlist**: any playlist and any duration text.
  - **strobe-io**: any UDP datagram decodes as OSC or is refused, never as
    more messages than eight-byte minimums fit; any bytes as MIDI.
  - **strobe-remote**: any client message text and any trust file.
  - **strobe-shadertoy**: any JSON as an export; a real export with its
    image pass's code replaced by generated GLSL converts or is refused,
    with bounded output; any text as a shader id.

  A failure is shrunk and written to that crate's
  `tests/properties.proptest-regressions`. The file is committed and
  replayed first on every run, so a found bug stays a fixture.
- **cargo-machete weekly**, in the Scheduled workflow (D536). Its first
  run found `toml` unused in strobe-io, now removed. It also flagged
  `md-5` in strobe-projector, wrongly, because the library is named
  `md5`; that is ignored in the crate's `[package.metadata.cargo-machete]`
  with the reason.
- **Coverage weekly**: cargo-llvm-cov 0.9.1 over strobe-scene,
  strobe-playlist, strobe-io, strobe-remote and strobe-projector. It
  writes an lcov artefact and a summary in the job. It has no threshold.
- **The Scheduled workflow runs on a pull request that changes it.** So a
  change to these jobs is tested before it lands, and cargo-deny runs on
  those pull requests too.
- **`docs/DECISIONS_BY_AREA.md`**, generated by `cargo xtask decisions`.
  It lists every decision under each crate it names (as `strobe-x` or
  `strobe_x`, whole words), under "CI and releases" when it names a
  workflow, and under "Not tied to one crate" otherwise. The `generated`
  lane checks it, so a new decision without a regenerated index fails CI.
  The numbers and files are unchanged. It lives beside `DECISIONS.md`,
  because every file in `docs/decisions/` must be a single decision.

**Trade-off.** The index is lexical. A decision about the remote that
never writes `strobe-remote` lands under "Not tied to one crate": 219 of
382 do today. Tagging each decision by hand would be more precise and
would drift. Property tests add a few hundred milliseconds per crate and
eight locked crates under `[dev-dependencies]`. None of them is linked
into `strobe.exe`. But `cargo metadata` unifies features across dev edges,
so `THIRD_PARTY.md` (D491) now credits `rand_core`, which proptest's
`rand` 0.10 brings in. Crediting one licence too many is harmless.

**Test.**
- The thirteen properties pass on LIGHTNING. The first run of the tag
  property failed on `"!Ⱥ"`: the input was fine, and the bound was wrong
  (lower-casing `Ⱥ` makes it longer). The bound was loosened, and that
  case was not kept.
- machete is clean after the two changes above.
- `xtask`'s tests cover titles, whole-word crate matching in both
  spellings, and the "not tied" section.
- The coverage and machete jobs first run on this pull request.

**Would reopen:** a parser found panicking in the field. Its input becomes
a regression fixture and the generator grows to cover its shape.
cargo-fuzz becomes worth a nightly lane only if the properties stop
finding what structured fuzzing would.
