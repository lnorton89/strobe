# D531: faster iteration: one file per decision, no shared summary lines, docs-only CI, and a client-list save that retries (2026-11-03, owner's request)

**Context.** On 2026-11-03 seven pull requests were merged one after
another. Each merge left the next one conflicting, always in the same two
places: the end of `docs/DECISIONS.md`, where every branch appended its
decisions, and the one-line "Last updated" summary at the top of
`docs/ROADMAP.md`, which every branch rewrote. Each fix was a new push and
a new ten-minute CI run. A docs-only pull request ran the full Windows,
macOS and Linux builds, and a flaky Windows test failed three runs.

**Decisions.**

- **One file per decision**, `docs/decisions/D<n>.md`. `DECISIONS.md` is
  now the folder's introduction. Branches that each add a decision touch
  different files. A clash on the number shows up as an add/add conflict on
  the file name, which is the right moment to renumber.
  `strobe_conventions::docs` reads the folder and checks that each file's
  name matches its heading.
- **No "Last updated" summary line** in `ROADMAP.md`.
  The summary repeated what the decision files and `CHANGELOG.md` already
  say, and it was the one line every branch edited. `git log` on a file is
  its history.
- **Docs-only pull requests skip the platform builds.** A `changes` job
  diffs the pull request. When every changed path is Markdown or under
  `docs/`, the Windows, macOS and Linux jobs are skipped, and a `docs` job
  runs the conventions tests (links, decision numbers, known gaps).
  Pushes, releases (D521) and manual runs always build everything.
- **The client list's save retries.** On Windows, access denied or a
  sharing violation while writing or renaming `clients.json` (an antivirus
  scan, the indexer, or another `Clients` saving the same file) is retried
  up to ten times, 20 ms apart. A failed save costs a paired client its
  token rotation. It also failed
  `paired_clients_survive_a_restart_and_revoke_all_clears_them` on Windows
  CI: the first server's disconnect handler saved on its own thread while
  the restarted server saved the same file. That test now prints the
  server's log when the rotation is missing.

**Would reopen:** decisions being edited in bulk again (a single file
would be easier then); a docs change that the platform builds would have
caught (images or data under `docs/` that a test reads).
